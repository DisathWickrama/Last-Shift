# Last Shift

A slow-burn psychological horror game about the night shift at an isolated mountain roadhouse. Inspect every traveller who comes out of the fog, then decide who gets served.

Built with Vite + TypeScript + HTML Canvas. No game engine and no asset files: every picture is drawn in code.

## Run it

```bash
npm install
npm run dev
```

Then open the address Vite prints (usually http://localhost:5173).
